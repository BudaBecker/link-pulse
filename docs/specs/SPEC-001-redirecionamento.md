# SPEC-001 — Redirecionamento de link curto

- **Status:** Substituída por SPEC-004
- **Requisitos:** nenhum; os requisitos que esta spec cobria passaram para a SPEC-004

O redirecionamento, o contador e o registro do clique fazem parte da [SPEC-004](SPEC-004-aplicacao.md), que cobre a aplicação inteira do Marco 2 ([ADR-0012](../decisoes/ADR-0012-marco-2-benchmark-sql-x-nosql.md)). Esta spec ficou em `Rascunho` até ser substituída e não teve implementação.
